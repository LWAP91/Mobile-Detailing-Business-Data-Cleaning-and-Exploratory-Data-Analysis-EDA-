# Mobile-Detailing-Business-Data-Cleaning-and-Exploratory-Data-Analysis-EDA-
# This project focuses on data cleaning and exploratory data analysis using pandas , matplotlib, Numpy libraries and  an generated dataset modeled after a mobile detailing business operating in Sarasota and Charlotte Counties during 2025.

# Data Cleaning 
# Taks Perfomed
- Standardized date formats and resolved invalid dates
- Cleaning numeric columns (prices, totals, tips) containing symbols and text
- Normalizing marketing channels (Instagram, Facebook, YouTube, TikTok, Referral)
- Handling missing values and removed duplicate records
- Creating a clean, analysis-ready dataset

# Repository Structure

- `detailing_2025_messydata.csv` – Raw dataset  
- `detailing_2025_cleandata.csv` – Clean dataset  
- `BN_detailing_Notebook.ipynb` – Full cleaning code

# Conclusion

This project demonstrates a structured, reproducible approach to transforming messy real-world data into a reliable dataset ready for analysis, visualization, and modeling.
